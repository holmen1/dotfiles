# X11

Everything about the X session in one place: startup, recovery, debugging, and
pointers to the component docs that own the details.

The stack is X11-only (no Wayland): **XLibre** display server, **xmonad** (Artix) or
**dwm** (FreeBSD), **st** terminal, custom **XKB** keymap, **dmenu** menus.

## Session startup

The session starts from a TTY with `startx`, which runs `~/.xinitrc`:

- Artix: [`config/artixinstall/.xinitrc`](../config/artixinstall/.xinitrc) — launches xmonad
- FreeBSD: [`config/bsdinstall/.xinitrc`](../config/bsdinstall/.xinitrc) — launches dwm

Both set a base XKB layout first, then `xkb-toggle` applies the custom compiled
keymap. On Artix the default layout is US on host `besk`, Swedish elsewhere.

`.xinitrc` no longer aborts when an essential program is missing — it logs to
`~/.xinitrc-errors.log` and continues. **If X starts but behaves oddly, check that
file first.**

Enter a TTY via `Ctrl+Alt+F2`, or disable a display manager if one is installed
(Arch: `sudo systemctl disable lightdm`; FreeBSD: not applicable).

Start something else instead of the configured WM:

```sh
startx /usr/bin/startxfce4
```

Leave the X session:

```sh
pkill x
```

### startx invocation

`startx` is invoked from `~/.bash_profile` with `-keeptty`:

```sh
exec startx -- -keeptty
```

`-keeptty` keeps the X server attached to the controlling TTY — required for
seat/session tracking without a display manager. See
[`install/build/xlibre/README.md`](../install/build/xlibre/README.md) for X server
troubleshooting (stale locks, DRM/seat issues, input drivers, fonts).

## TTY switching & black screen recovery

### Linux (Artix)
- `Ctrl+Alt+F2` through `Ctrl+Alt+F6` — switch to TTY console
- `Ctrl+Alt+F7` — return to the X session

### FreeBSD (XLibre)
- `Alt+F1`, `Alt+F2`, etc. — cycle virtual consoles (if keyboard responds)
- `Scroll Lock` then arrow keys — alternative console switching
- `Ctrl+Alt+Delete` or power cycle — last resort reboot

Once at a TTY:

```sh
ps aux | grep X           # check if X is running
pkill -9 X                # kill a stuck X server
startx                    # restart the X session
```

## Display manager

This setup normally runs without a display manager. To enable one, confirm
`.config/xmonad/xmonad-session-rc` is linked, then edit `xmonad-session`:

```
$ diff /usr/bin/xmonad-session /usr/bin/xmonad-session.bak
3c3
< if [ -r ".config/xmonad/xmonad-session-rc" ]
---
> if [ -r ".xmonad/xmonad-session-rc" ]
5c5
<   . .config/xmonad/xmonad-session-rc
---
>   . .xmonad/xmonad-session-rc
```

## Debugging

Key bindings:

```sh
xbindkeys -k          # press a key to see its keycode
xev                   # show all X events (key press, window focus, etc.)
```

Windows:

```sh
xprop                 # click a window to see properties
xwininfo              # click a window to see geometry and ID
xdotool search --name "window title"  # find a window by name
```

XKB keymaps have their own debugging commands (`xkbcomp`, `setxkbmap -print`) —
see [`config/xkb/README.md`](../config/xkb/README.md).

XMonad deployment issues (stale binary, `--recompile`/`--restart` behavior) —
see [`install/build/xmonad/LESSONS_LEARNED.md`](../install/build/xmonad/LESSONS_LEARNED.md).
