# X11

The stack is X11-only (no Wayland): **Xorg** or **XLibre** (Artix) / **XLibre** (FreeBSD),
**xmonad** (Artix) or **dwm** (FreeBSD), **st** terminal, custom **XKB**
keymap, **dmenu** menus.

## Session startup

The session starts from a TTY with `startx`, which runs the shared
[`config/common/.xinitrc`](../config/common/.xinitrc). It selects the terminal,
window manager and base XKB layout from `install/hosts/<OS>/<hostname>.conf`;
`xkb-toggle` uses the same layout when restoring the base keymap.

Re-link the host profile after updating to migrate an existing Artix or FreeBSD
`.xinitrc` symlink to the common stow package.

```sh
~/repos/dotfiles/install/hosts/scripts/link_config.sh \
    ~/repos/dotfiles/install/hosts/$(uname -s)/$(hostname -s).conf
```

Missing essential programs are logged to `~/.xinitrc-errors.log`. A missing or
invalid host profile stops startup. **If X starts but behaves oddly, check the
log first.**

Enter a TTY via `Ctrl+Alt+F2`, or disable a display manager if one is installed
(Arch: `sudo systemctl disable lightdm`; FreeBSD: not applicable).

Start something else instead of the configured WM:

```sh
startx /usr/bin/startxfce4
```

Leave the X session:

```sh
pkill x
```

### startx invocation

`startx` is invoked from `~/.bash_profile` with `-keeptty`:

```sh
exec startx -- -keeptty
```

`-keeptty` keeps the X server attached to the controlling TTY — required for
seat/session tracking without a display manager. See
[`install/build/xlibre/README.md`](../install/build/xlibre/README.md) for X server
build details.

## XLibre on FreeBSD

On FreeBSD, use `startx -- -keeptty` from the first launch. Without it, XLibre
may start but fail to receive input because the controlling TTY was not kept
for libseat.

FreeBSD's `/etc/X11` may be empty: XLibre also reads vendor configuration from
`/usr/local/share/X11/xorg.conf.d/` and local overrides from
`/usr/local/etc/X11/xorg.conf.d/`. Check these paths for driver snippets. A
configured driver does not necessarily prevent XLibre from probing another
driver for the same GPU; use the log to confirm which drivers were selected
before adding overrides. Some failed fallback-driver loads are harmless if
the server successfully selected the needed driver.

## General X server troubleshooting

When startup fails, inspect the X server log before repeatedly restarting or
changing permissions.

If a failed X session left stale locks or sockets, first confirm that no X
server is still running, then remove the stale files before retrying:

```sh
rm -f /tmp/.X*-lock /tmp/.X11-unix/X*
```

To separate display-server problems from window-manager startup problems,
test with a minimal client such as `xterm`. On Artix, if the log reports an
empty font path or a missing `fixed` font, install `xorg-fonts-misc` and
`xorg-mkfontscale`.

## TTY switching & black screen recovery

### Linux (Artix)
- `Ctrl+Alt+F2` through `Ctrl+Alt+F6` — switch to TTY console
- `Ctrl+Alt+F7` — return to the X session

### FreeBSD (XLibre)
- `Alt+F1`, `Alt+F2`, etc. — cycle virtual consoles (if keyboard responds)
- `Scroll Lock` then arrow keys — alternative console switching
- `Ctrl+Alt+Delete` or power cycle — last resort reboot

Once at a TTY:

```sh
ps aux | grep X           # check if X is running
pkill -9 X                # kill a stuck X server
startx                    # restart the X session
```

## Display manager

This setup normally runs without a display manager. To enable one, confirm
`.config/xmonad/xmonad-session-rc` is linked, then edit `xmonad-session`:

```
$ diff /usr/bin/xmonad-session /usr/bin/xmonad-session.bak
3c3
< if [ -r ".config/xmonad/xmonad-session-rc" ]
---
> if [ -r ".xmonad/xmonad-session-rc" ]
5c5
<   . .config/xmonad/xmonad-session-rc
---
>   . .xmonad/xmonad-session-rc
```

## Debugging

Key bindings:

```sh
xbindkeys -k          # press a key to see its keycode
xev                   # show all X events (key press, window focus, etc.)
```

Windows:

```sh
xprop                 # click a window to see properties
xwininfo              # click a window to see geometry and ID
xdotool search --name "window title"  # find a window by name
```

XKB keymaps have their own debugging commands (`xkbcomp`, `setxkbmap -print`) —
see [`config/xkb/README.md`](../config/xkb/README.md).

XMonad deployment issues (stale binary, `--recompile`/`--restart` behavior) —
see [`install/build/xmonad/LESSONS_LEARNED.md`](../install/build/xmonad/LESSONS_LEARNED.md).

Machine-specific kernel/display quirks (e.g. Framework AMD panel redraw, RDSEED) — see [`docs/hardware.md`](hardware.md).

## Input devices

On FreeBSD, brightness-key support may require
`acpi_video_load="YES"` in `/boot/loader.conf`. This is a hardware-specific
ACPI/backlight setting, separate from XLibre configuration.

### Touchpad tap-to-click (libinput)

Create `/etc/X11/xorg.conf.d/90-touchpad.conf`:

```conf
Section "InputClass"
  Identifier "touchpad tap-to-click"
  MatchIsTouchpad "on"
  Driver "libinput"
  Option "Tapping" "on"
EndSection
```

Restart the X session. For a temporary test, `xinput` (from `xorg-xinput`)
can toggle the device's `libinput Tapping Enabled` property.
